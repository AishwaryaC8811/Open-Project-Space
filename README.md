# Open-Project-Space
Space phenomena webpage

## 🌟 Highlights

- **Simple functionality** Information is organized in sections with descriptions
- **User friendly** Clear to understand and no prior knowledge is needed prior to using the webpage
- **Flexible** Great for individuals that want to learn as little or as much of space phenomena
- **Educational** Helps individuals understand and learn more about space phenomena. Great for students, researchers, or people that are simply interested. 


## ℹ️ Overview

The purpose of this project is to provide valuble, fundemental space information in an easy to understand format. This webpage provides information about the planets and their history, the kuiper belt, oort cloud, nebulaes, matter and much more. We had used HTML and CSS to develop this webpage. We had wrote the research in HTML and used CSS to format it as well as change the style of the page. This webpage is space themmed and includes great information for any occasion. 


## 🚀 Usage
1. Make sure Live Server is installed
2. Open the main branch 
3. Open the server via the button on the bottom right corner
4. Use the webpage as desired. Click on the various boxes and pictures to dive deeper into the amazing space phenomena.
